## 🚀 Featured Projects

### 🤖 AI Interview Coach &nbsp;*(Apr 2026 – May 2026)*
> Mock interview platform that parses uploaded resumes and uses the Groq API to generate dynamic, role-specific questions tailored to the candidate's profile.

- Delivered personalised, actionable feedback to improve technical communication and interview readiness
- Deployed publicly on Vercel — full interview simulation accessible end-to-end
- **Stack:** React.js · Node.js · Express.js · MongoDB · Groq API · Tailwind CSS

[![GitHub](https://img.shields.io/badge/Source%20Code-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Kavisanah/ai-interview-coach)
[![Live Demo](https://img.shields.io/badge/Live%20Demo-000000?style=flat-square&logo=vercel&logoColor=white)](https://ai-interview-coach-app-pi.vercel.app/)

---

### 💊 MediRemind &nbsp;*(Mar 2026 – May 2026)*
> Secure, role-based platform for managing medication schedules, tracking adherence, and booking medical appointments.

- Implemented automated reminder notifications using Spring Boot and a fully responsive React.js frontend
- Containerised the full-stack application with Docker for consistent, reproducible deployment
- **Stack:** React.js · Spring Boot · Spring Security · MySQL · JWT · Docker · Tailwind CSS

[![GitHub](https://img.shields.io/badge/Source%20Code-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Kavisanah/mediremind)

---

### 📚 Book Fair Management System &nbsp;*(Oct 2025 – Jan 2026)*
> Full-stack web platform for digitised stall reservations — vendors browse genre-based stalls, book online, and process payments.

- Implemented JWT authentication with RBAC and a QR-code-based entry verification system sent via email
- Built an admin dashboard for real-time stall tracking, reservation management, reporting & refund processing
- **Stack:** React.js · Spring Boot · Tailwind CSS · Framer Motion · JWT · MySQL · ZXing

[![GitHub](https://img.shields.io/badge/Source%20Code-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Sathiyabalan29/BookFair)
